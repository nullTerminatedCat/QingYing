# 青影 v0.3.0

青影是一款简洁好看的 Windows 截图工具。本版本完成第一至第三期规划：截图与标注、效率工具、智能识别与录屏。提供 Windows x64 安装包（setup.exe）和免安装 ZIP（portable.zip），并附 SHA256 校验文件。

## 功能一览

**截图与标注**
- 托盘常驻，全局热键（默认 `Ctrl+Alt+A`，可修改，冲突时提示），单实例运行
- 冻结所有显示器，每块屏幕按自身 DPI 像素精确截取；自动识别窗口 / 控件（`Tab` 切换）；圆形放大镜显示 HEX / RGB
- 标注：矩形、椭圆、箭头、画笔、多行文字、马赛克、序号；8 种颜色、3 档粗细 / 字号；撤销 / 重做
- 完成：复制、`Ctrl+S` 快速保存、`Ctrl+Shift+S` 另存为、`F3` 钉图；Enter / 双击的默认动作可在设置中选择

**效率**
- 钉图：拖动、滚轮缩放、`Ctrl`+滚轮透明度、旋转、翻转；托盘一键显示 / 隐藏 / 关闭全部钉图
- 滚动长截图（`L`）：自动滚动并拼接，实时预览
- 延时截图 3 / 5 / 10 秒
- 截图历史：托盘「最近截图」和历史窗口，可再次复制、钉图

**智能（本版新增）**
- 离线文字识别（`O`）：使用 Windows 自带 OCR，优先简体中文，结果可编辑并保留换行
- 二维码 / 条码识别（`Q`）：识别到网址时确认后可在浏览器打开
- 取色器：托盘「取色」，多种色值格式可选
- 录屏：MP4（H.264）或 GIF，帧率 10 / 15 / 30，可选录制鼠标指针；迷你控制条支持暂停、停止、计时，且不会被录进画面

## 安装

- **安装包**：运行 `QingYing-0.3.0-windows-x64-setup.exe`。默认只为当前用户安装，无需管理员权限；可选创建桌面快捷方式、开机自启。安装或卸载时会自动关闭正在运行的青影，卸载会移除开机自启项。
- **免安装版**：解压 `QingYing-0.3.0-windows-x64-portable.zip`，运行 `QingYing.exe`。设置保存在当前用户注册表中。
- 已附带 Qt 6.9.1 与 VC++ 运行库，无需另外安装。系统要求：Windows 10 2004 或更高版本（x64）。

## 已知问题

- 程序未进行代码签名，首次运行时 Windows SmartScreen 可能提示，选择"仍要运行"即可。
- OCR 需要系统已安装对应语言的 OCR 组件；未安装中文时只能识别系统当前语言，详见 README。
- 选区暂不支持跨显示器。
- 录屏使用 GDI 抓帧，高分辨率 / 30 fps 下 CPU 占用较高；GIF 适合短片段；暂不录音。
- 长截图依赖目标程序响应鼠标滚轮，固定底栏或动画页面可能拼接不准。

## 校验

下载后可用 PowerShell 校验：`Get-FileHash <文件> -Algorithm SHA256`，与 `SHA256SUMS-0.3.0-x64.txt` 对比。
