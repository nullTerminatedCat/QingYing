# 青影 QingYing · 第一期 UI 设计规范 v2

**理念**：轻、少、浮。界面只露出必要的控件，二级选项只在选中工具后出现。参考 Windows 11 Fluent 和 macOS 的质感：浮动圆角、柔和阴影、亚克力模糊。

## 色板
| Token | 值 | 用途 |
|---|---|---|
| accent | #4F6BFF | 唯一强调色：选区、选中工具、开关、链接 |
| accent-hover | #3D57E8 | 悬停和按下 |
| accent-tint | rgba(79,107,255,.12) | 菜单悬停和选中底色 |
| text | #1C1C1E | 主文字 |
| text-2 | #6E6E73 | 次要文字 |
| text-3 | #A1A1A6 | 提示、快捷键 |

标注色（8 个）：#FF453A（默认）、#FF9F0A、#FFD60A、#32D74B、#4F6BFF、#BF5AF2、#1C1C1E、#FFFFFF。

## 字体
Segoe UI Variable / Microsoft YaHei UI。字号 12（标签）/ 13（正文）/ 20（页面标题），字重只用 400、500、600。色值用 Consolas。

## 尺寸
- 间距用 4 的倍数，常用 8 / 12 / 16 / 24。
- 圆角：工具条和菜单 14，设置卡片 10，按钮 10，标签 8，选区手柄为圆点。
- 阴影：0 10px 40px rgba(20,24,40,.18) 叠加 0 2px 8px rgba(20,24,40,.08)。
- 工具条：按钮 36×36，图标 19，内边距 6，按钮间距 4，放在选区下方 14px 处，与选区右边对齐；放不下时放到上方，再放不下就放进选区内部。二级样式条在工具条下方 8px，只在选中工具时出现。

## 图标
24 网格，1.5px 线宽，圆角端点，单色，颜色随文字。

## 状态
- 默认：透明底。
- 悬停：底色 rgba(0,0,0,.05)；深色工具条用 rgba(255,255,255,.08)。
- 选中：底色 accent，图标白色，带 accent 光晕阴影。
- 禁用：不透明度 30%。
- 确认（✓）：图标用 accent 色，回车也可确认。
- 提示气泡：悬停 600ms 后显示「名称  快捷键」。

## 页面
- 01a 窗口识别：窗口外加遮罩，窗口描 2px accent 边、铺 6% 底色，用标签显示「窗口名 · 宽×高」。
- 01b 区域选择：选区 4 角为圆点手柄，左上角上方显示尺寸标签；圆形放大镜 132px，13×13 像素网格，下方标签显示 HEX 和 RGB。
- 02 工具条：7 个标注工具 | 撤销、重做 | 钉图、保存、取消、确认。二级条为 3 档粗细和 8 个颜色；选文字工具时粗细换成字号和加粗。02b 为深色工具条。
- 03 标注示例：各工具的实际效果。
- 04 钉图：圆角 10，带 1.5px accent 描边和大阴影；悬停时右上角显示 复制、保存、关闭，左下角显示缩放比例；未悬停的钉图半透明。
- 05 托盘菜单（5 项）和设置窗口：卡片式设置行，快捷键、保存位置、格式（分段控件）、开机启动开关、截图后自动保存开关。
