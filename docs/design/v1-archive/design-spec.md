## 2. 字体
- 界面文字："Microsoft YaHei UI"，回退 Segoe UI。字号沿用青匣：11 / 12 / 13（正文）/ 15（分组标题）/ 18–19（页面标题）px。
- 数字、坐标、色值、快捷键用 Consolas 12px。
- 标注文字默认 16px，可选 12–48，支持加粗。

## 3. 间距与圆角
- 4px 栅格，常用间距 4 / 8 / 12 / 16 / 24。
- 圆角：工具按钮 6，输入框和按钮 6，工具条、菜单、窗口 8，大卡片 10，标签 4，开关 10（胶囊形）。
- 工具条：内边距 5，按钮 32×32，图标 18，分隔线 1×20，位于选区下方 8px 处；下方空间不够时放到选区上方，再不够就放进选区内部。二级样式条在工具条下方 8px，左对齐。
- 阴影：浮层 0 6px 20px rgba(18,63,57,.25)，钉图 0 12px 36px rgba(0,0,0,.45)。

## 4. 图标
- 24 网格，1.7px 线宽，圆角端点，单色线性图标（currentColor），与青匣 resources/icons/*.svg 风格一致。
- 名称：rect、ellipse、arrow、pen、text、mosaic、num、undo、redo、pin、save、copy、close、crop、gear、folder、screen、power、info，SVG 路径见 icons.js。

## 6. 页面说明
1. **01a 窗口识别**：鼠标悬停时识别窗口和控件，区域用 #4AA18F 描 2px 边并铺 10% 底色，左上角标签显示「窗口名 · 宽 × 高」。
2. **01b 区域选择**：选区外遮罩 48%，选区描边 1.5px，8 个手柄（8×8，白底青边），选区左上角上方显示尺寸标签。放大镜 150×150，显示 15×15 像素、每像素 10px，带网格和十字线，下方读数为坐标、RGB 和 HEX；按 C 复制色值，按 Shift 切换格式。放大镜默认在光标右下方，碰到屏幕边缘时翻转到另一侧。
3. **02 标注工具条**：顺序为 矩形 R、椭圆 E、箭头 A、画笔 P、文字 T、马赛克 M、序号 N | 撤销、重做 | 钉图 F3、保存 Ctrl+S、取消 Esc、复制 Enter。
4. **03 标注示例**：各工具的实际效果；序号为 24px 红色圆加白边，自动递增。
5. **04 钉图**：无边框置顶窗口，带 1px #4AA18F 描边和阴影；悬停时右上角显示工具条，左下角显示缩放比例和不透明度；右键弹出菜单；滚轮缩放，Ctrl+滚轮调不透明度，双击或 Esc 关闭。
6. **05 托盘和设置**：托盘菜单顶部为品牌区，下方分组为截图、目录和设置、退出；设置窗口 620×520，左侧导航（常规、快捷键、保存、关于）。
