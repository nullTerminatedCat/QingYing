# 青影 v0.6.5

修正取色快捷键占用 Tab，并增加全局录屏热键。

## 变更
- **不再用 Tab 切换取色格式**：`Tab` 只保留截图时的窗口 / 控件识别；取色与放大镜改用 **`[` / `]`** 或 **滚轮** 切换格式
- **录屏热键**：默认 `Ctrl+Alt+R`（设置 → 常规可改）；开始框选录制 MP4，录制中再按一次停止并保存；与截图热键冲突或被占用时有提示
- 托盘提示与菜单显示截图 / 录屏两个热键

## 建议手测
- 截图悬停时按 Tab：应切换「窗口 / 窗口+控件」，不应改颜色格式
- 托盘取色：`[` / `]`、滚轮切格式，`C` 复制；设置改默认格式后仍生效
- `Ctrl+Alt+R` 框选录制，再按一次停止；设置里改热键与冲突提示
