# 青影 QingYing 0.7.1

在 0.7.0（RapidOCR + OpenAI 兼容翻译）之上，补上设置说明、减少无用翻译请求，并增加「识别并翻译」入口。

## 设置说明

- 设置 → 截图 → 翻译：「？」说明如何申请并填写 OpenAI / DeepSeek 的接口地址、密钥和模型（密钥仍只保存在本机，不会进仓库）。

## 少打 API

- 原文已是目标语言、无实质正文（纯数字/标点/链接等）时跳过请求。
- 同一识别结果、同一方向短时复用缓存；翻译中防连点；关闭面板时尽量取消未完成请求。
- 避免「译完又立刻往回翻」的无意义往返。

## 识别并翻译

- 截图工具条新增「识别并翻译」（钉图右键菜单同样有）。
- 默认全局热键 `F`（设置 → 常规可改；与截图 / 录屏冲突时会提示）。未改过这项设置的安装会用 `F`；已经保存过自定义热键的保持原设置。
- 框选后一次完成 OCR，并按文字语言自动翻译；翻译未开启或未配好时仍显示识别结果并说明原因。

## 怎么验

1. 设置里打开「？」核对 DeepSeek / OpenAI 填写说明。
2. 对已是中文的识别结果点「译成中文」，应跳过请求。
3. 用 `F` 或工具条「识别并翻译」走通识别 + 翻译。
