# 青影 v0.5.1

本版本为体验打磨补丁，不引入大功能。提供 Windows x64 安装包（setup.exe）和免安装 ZIP（portable.zip），并附 SHA256SUMS 校验文件。0.5.0 用户可通过托盘「检查更新」直接升级。

## 改进

- **识别面板**：识别进行中编辑框只读并禁用复制/翻译，避免误操作；复制成功后约 1.5 秒显示「已复制」再恢复；切换界面语言时刷新按钮文案。
- **翻译提示**：网络超时、无法连接、SSL 失败、服务额度用尽等改为更易懂的中文说明；设置中关闭联网翻译后再次点击会提示并隐藏按钮。
- **历史记录**：复制图片后按钮短暂显示「已复制」；空状态文案样式随浅色/深色主题。
- **录屏**：暂停时迷你条时间旁显示「暂停」。
- **检查更新**：遇到 GitHub 接口限流或网络问题时给出更明确的提示。
- **文档**：修正 v0.5.0 Release 页中 MyMemory 相关笔误，与仓库说明一致。

## 已知问题

- 选区不能跨显示器：混合 DPI 下无法保证像素精确，因此按屏选区。
- 以下情况录屏会改用 GDI，CPU 占用较高：旋转屏、跨显示器区域、部分远程桌面。GIF 最多 256 色，暂不支持录音。
- 钉图 / 历史再编辑时，比屏幕大的图片会先缩小到屏幕大小。
- 切换语言时，已经打开的识别结果窗口标题文案不会自动换成新语言的「文字识别」等（按钮会刷新），重新打开即可。
- 翻译依赖外网访问 MyMemory；网络不通、服务限流或被拦截时会失败并提示，可稍后重试或在设置中关闭。
- 未登录 GitHub 的更新检查受频率限制（每 IP 每小时 60 次）。
