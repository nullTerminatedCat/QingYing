# 青影 v0.6.2

本版打磨「检查更新」界面，并顺手修一批窗口标题与小体验问题。

## 实际改进

- **检查更新等待框**：去掉系统原生细灰进度条，改为与设置页一致的靛蓝主题色卡片；标题改为「检查更新」（不再出现「青影 · 更新 - 青影」）。
- **可取消**：检查过程中可点「取消」中止请求。
- **结果 / 下载标题**：发现新版本、下载、校验、准备安装等对话框标题去掉重复的「青影 ·」前缀；下载进度条套用主题色样式。
- **窗口标题统一**：设置、历史、钉图、长截图、识别结果、关于等窗口标题不再自带「青影」，避免系统拼上应用名后重复。
- **历史空状态**：空列表提示改用主题次要文字色与更舒适的行距。
- **识别结果状态色**：切换普通 / 错误状态时正确刷新样式（不再被空 stylesheet 冲掉）。
- **录屏迷你条**：暂停时指示点与边框改为琥珀色，继续录制恢复红色。

## 验证

- 本机 Release x64 零警告编译；QtTest 全部通过。
- 冒烟脚本覆盖启动与基本路径。
- 手动建议：设置 / 托盘点「检查更新」，确认等待框样式与标题、可取消；再确认「已是最新」对话框标题为「已是最新版本 - 青影」。

- QingYing-0.6.2-windows-x64-setup.exe：Windows x64 安装包。
- QingYing-0.6.2-windows-x64-portable.zip：免安装版，解压后运行 QingYing.exe。
