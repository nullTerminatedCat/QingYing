# 青影 v0.5.0

本版本补上第三期规划中的 **OCR 结果翻译**。提供 Windows x64 安装包（setup.exe）和免安装 ZIP（portable.zip），并附 SHA256SUMS 校验文件。0.4.x 用户可通过托盘「检查更新」直接升级。

## OCR 结果翻译

- 文字识别完成后，结果面板提供 **翻译**（按文本自动选择中↔英方向）、**译成中文**、**译成英文**。
- 自动检测源语言（经 MyMemory）；长文按行分块请求，尽量保留换行。
- 翻译过程中编辑框只读并显示「正在翻译…」；失败时用红色状态说明原因。
- 译完后可继续编辑、复制，或点 **还原原文**。
- 默认启用，**无需 API Key**；在 **设置 → 截图 → 联网翻译 OCR 结果** 可关闭。关闭后识别面板不再显示翻译按钮。
- 仅发送识别出的文本，不上传截图图片。免费接口有额度限制，频繁使用可能被服务端限流。

## 其他

## 已知问题

- 选区不能跨显示器：混合 DPI 下无法保证像素精确，因此按屏选区。
- 以下情况录屏会改用 GDI，CPU 占用较高：旋转屏、跨显示器区域、部分远程桌面。GIF 最多 256 色，暂不支持录音。
- 钉图 / 历史再编辑时，比屏幕大的图片会先缩小到屏幕大小。
- 切换语言时，已经打开的识别结果窗口不会刷新文字，重新打开即可。
- 翻译依赖外网访问 MyMemory；网络不通、服务限流或被拦截时会失败并提示，可稍后重试或在设置中关闭。
- 未登录 GitHub 的更新检查受频率限制（每 IP 每小时 60 次）。
