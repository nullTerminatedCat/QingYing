# 青影 QingYing 0.7.3

在 0.7.2 之上，把「截图秒答」与「一键改文案」的操作路径收短：少点菜单、键盘能走完常用动作。

## 改文案一键芯片

- 识别结果面板直接出现「更礼貌 / 更短 / 更正式 / 润色」芯片，一点即改，不必再进二级菜单。
- 钉图菜单里的改写项同样拍平，少点一步。

## 提问更顺手

- 提问框支持 **Enter** 发送；正在编辑正文时，用 **Ctrl+Enter** 提问。
- 快捷键：**Ctrl+1..4** 对应四种改写；空闲时 **Esc** 关闭结果面板。

## AI 未配置时

- 未配置 OpenAI 兼容地址 / 密钥时，结果面板提供「打开设置」，点一下就能去配，不必先关掉面板再找托盘。

## 怎么验

1. 框选识别出文字后，结果面板应直接看到四个改写芯片；点「更短」应立刻请求并回填。
2. 在提问框输入后按 Enter（或编辑正文时 Ctrl+Enter）应发起秒答。
3. 未配置 AI 时，点「打开设置」应进入设置中的 AI 相关页。
4. 空闲时按 Esc 应关闭结果面板；请求进行中 Esc 不中断关闭。
