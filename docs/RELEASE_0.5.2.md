# 青影 v0.5.2

本版本修复「检查更新没反应」：手动检查全程弹窗反馈，GitHub API 限流时回退到发布页跳转解析版本。提供 Windows x64 安装包（setup.exe）和免安装 ZIP（portable.zip），并附 SHA256SUMS。

**仍在使用 0.4.2 的用户**：旧版在检查失败时只发托盘气泡，Windows 常会吞掉，看起来像没反应。请直接下载本页的 `QingYing-0.5.2-windows-x64-setup.exe` 覆盖安装；安装后再用「检查更新」验证。

## 修复

- **手动检查必有反馈**：点击后立即出现「正在检查更新…」进度框；结束后用消息框提示「已是最新 / 发现新版本 / 失败原因」，不再只依赖托盘气泡。
- **API 限流回退**：`api.github.com` 返回 403/429 或网络失败时，改用 `github.com/.../releases/latest` 跳转解析最新标签；无资源列表时引导打开发布页下载。
- **日志**：检查过程写入日志（manual/http/err/tag），便于排查。
- **下载失败**：安装包下载/校验失败也改为消息框提示。

## 已知问题

- 选区不能跨显示器。
- 部分场景录屏回退 GDI；GIF 最多 256 色，暂不支持录音。
- 翻译依赖外网 MyMemory。
- 未登录 GitHub 时 API 仍有频率限制；本版会在限流后自动走网页回退。

## 校验

SHA-256 见 Release 附件中的 SHA256SUMS 文件。
