# 青影 v0.6.6

放大镜色值提示不再裁切，双屏下 Tab 窗口识别跟随光标。

## 变更
- **取色信息条**：按当前格式自动加宽；显示格式名 + 完整色值（`rgba` / `hsl` / `hsv` / HEXA / BGR 等不再被截断）；贴边时翻到光标另一侧
- **双屏 Tab**：`Tab` 切换「窗口 / 窗口+控件」在所有屏幕同步；鼠标移到另一屏后键盘焦点跟随，该屏即可继续用 Tab / Esc 等快捷键
- 格式切换仍为 **`[` / `]`**、滚轮或设置，**不占用 Tab**

## 建议手测
- 取色或截图放大镜：切换到 `rgba` / `hsl` / `hsv` / HEXA，色值应完整可见；靠近屏幕边缘时提示条应翻侧且不裁切
- 双屏：在 A 屏启动截图，移到 B 屏按 Tab，B 屏高亮应在「窗口」与「窗口+控件」间切换
- Tab 仍只切窗口识别，不切颜色格式
