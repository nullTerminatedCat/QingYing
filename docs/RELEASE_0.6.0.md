# 青影 v0.6.0

本版集中改善长截图的拼接质量、处理速度和保存体验。

## 实际改进

- **固定栏不再反复拼入**：自动识别静态固定顶栏和底栏，按中间滚动内容匹配位移。最终保留开头的一份顶栏和结尾的一份底栏。
- **长图处理更轻**：新增内容以条带保存，预览只绘制最新部分，输出时才合成完整图像，减少反复分配和复制整张长图。
- **等待画面稳定**：匹配失败后重试当前画面，避免继续滚动造成内容跳失。连续失败时保留已捕获的内容。
- **保存失败可恢复**：保存失败后保留长图和结果面板，可以重试，或用新增的「另存为」切换保存位置；取消另存为也不会丢失结果。
- **更顺手的结果面板**：显示已拼接帧数和像素尺寸；停止后支持 `Ctrl+C` / `Enter` 复制、`Ctrl+S` 保存、`Ctrl+Shift+S` 另存为、`F3` 钉图、`Esc` 关闭。停止后释放全局 Esc，避免干扰保存对话框。
- **长图容量保护**：最多 30,000 像素高或 64 Mi 像素（RGB32 图像约 256 MiB）；达到上限时停止并保留已有结果，分配失败时也不丢弃已捕获内容。
- 新增文案提供简体中文和英文。

## 验证

- 45 项 QtTest 用例全部通过，包括固定顶栏、固定底栏、双固定栏、小滚动区域、留白边界、多帧小步滚动、逐像素输出一致性和容量边界。
- 本机 Release x64 基准：80 帧、每次新增 120 行、最终 1280×10200 像素。三次测量中旧循环耗时 595–634 ms，新实现 28–36 ms，约 17.6–22.3 倍加速，最终像素完全一致。基准包含拼接、预览与最终合成，不包含屏幕抓取、滚动等待或位移匹配；实际速度取决于电脑和页面。
- 独立冒烟模式验证启动、系统 OCR、语言切换和正常退出。
- 隔离的 Qt 离屏交互检查通过：保存失败保留窗口和图像、`Ctrl+S` 重试成功且像素一致、`Ctrl+C` / `Enter` 复制、`Esc` 关闭。

- `SHA256SUMS-0.6.0-x64.txt`：以上两个文件的 SHA-256 校验值。
