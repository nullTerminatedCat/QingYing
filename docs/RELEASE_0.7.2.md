# 青影 QingYing 0.7.2

在 0.7.1 之上合入两条体验改动：识别并翻译默认热键改为单键 **F**，以及「截图秒答」与「一键改文案」。

## 识别并翻译默认热键 F

- 出厂默认由 `Ctrl+Alt+T` 改为单键 `F`（设置 → 常规可改；与截图 / 录屏冲突时会提示）。
- 未改过这项设置的安装会用 `F`；已经保存过自定义热键的保持原设置。
- 设置里可登记不带修饰键的热键，以便恢复默认。

## 截图秒答

- 框选或钉图识别文字后，可针对选区内容向 AI 提问（这是什么 / 怎么解 / 怎么修等）。
- 共用设置里已配置的 OpenAI 兼容地址、密钥和模型；没有文字不请求，相同内容约两分钟内不重复请求。
- 默认全局热键 `Ctrl+Alt+D`（可在设置中修改）。

## 一键改文案

- 对识别结果按预设语气改写：更礼貌 / 更短 / 更正式 / 润色。
- 与秒答同一条 AI 链路，结果可复制。

## 怎么验

1. 新装或清过热键设置后，按 `F` 应触发「识别并翻译」。
2. 配置好 AI 后，用 `Ctrl+Alt+D` 或工具条「秒答」对一段文字提问。
3. 在识别结果面板试「更礼貌 / 更短 / 更正式 / 润色」。
