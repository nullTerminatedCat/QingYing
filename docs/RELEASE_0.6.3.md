# 青影 v0.6.3

本版重点重做「检查更新」里的不确定进度条，并保留 0.6.2 的对话框与其它体验打磨。

## 实际改进

- **进度条重做**：检查更新等待态不再使用 Windows 原生不确定进度条（细灰轨道 + 系统蓝块），改为自绘靛蓝滑动指示条，圆角轨道，跟 #4F6BFF 主题一致。
- **检查更新对话框**：标题为「检查更新」（不再「青影 · 更新 - 青影」）；可取消；结果仍用可见对话框。
- **下载进度**：安装包下载进度条强制 Fusion + 主题色 chunk，避免系统细条观感。
- **其它打磨（随 0.6.2）**：设置 / 历史 / 钉图 / 长截图 / 识别 / 关于窗口标题去重；历史空状态；识别错误状态色刷新；录屏暂停指示改为琥珀色。

## 验证

- 本机 Release x64 零警告编译；QtTest 全部通过。
- 手动建议：点「检查更新」，确认中间是靛蓝圆角滑动条而非系统原生进度条；可点取消。

- QingYing-0.6.3-windows-x64-setup.exe：Windows x64 安装包。
- QingYing-0.6.3-windows-x64-portable.zip：免安装版，解压后运行 QingYing.exe。
