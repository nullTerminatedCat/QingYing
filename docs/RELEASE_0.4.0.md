# 青影 v0.4.0（草稿）

本版本完成第四期「打磨」：主题、多语言、自动更新与上传插件。提供 Windows x64 安装包（setup.exe）和免安装 ZIP（portable.zip），并附 SHA256SUMS 校验文件（自动更新依赖此文件）。

## 新增

**主题**
- 浅色 / 深色 / 跟随系统，在设置 →「外观」切换；跟随系统时实时响应 Windows 颜色模式变化
- 截图工具条、钉图、设置、历史、识别结果、录屏控制条均有深色样式，主色保持 `#4F6BFF`

**多语言**
- 简体中文 / English / 跟随系统（设置 →「语言」），切换后重启青影生效
- 翻译基于 Qt Linguist（`i18n/*.ts`），内嵌于程序

**自动更新**
- 启动 8 秒后自动检查（每天最多一次，可在设置中关闭），托盘「检查更新」随时手动检查
- 发现新版本时显示版本说明；安装版下载 setup.exe（显示进度），按 SHA256SUMS 校验通过并经确认后启动安装程序并退出
- 免安装版改为打开发布页

**上传（默认关闭）**
- 设置 →「上传」启用后，截图工具条出现「上传」（`U`），钉图右键菜单也可上传，成功后链接自动复制到剪贴板
- 内置 SM.MS、Imgur 预设与自定义 HTTP（multipart POST：地址、文件字段、请求头、JSON 链接路径如 `data.url`）
- 令牌与请求头使用 Windows DPAPI 加密保存，仅当前用户可解密，不以明文写入配置

## 已知问题
- 托盘菜单图标为固定中性灰，不随主题切换
- Qt 内置对话框（如文件选择框按钮）文字未翻译
- 语言切换需重启生效
- 未经 GitHub 认证的更新检查受 API 频率限制（每 IP 每小时 60 次），频繁手动检查可能提示失败
