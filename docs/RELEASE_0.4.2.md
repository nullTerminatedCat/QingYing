# 青影 v0.4.2

本版本重做了设置页，并修复了一批细节问题。提供 Windows x64 安装包（setup.exe）和免安装 ZIP（portable.zip），并附 SHA256SUMS 校验文件。0.4.x 用户可通过托盘「检查更新」直接升级。

## 设置页重做

- **侧栏导航**：分为常规、截图、标注、录屏、上传、外观与语言、关于与更新七页，每页用分组卡片排列，每项都带一行说明。
- **更顺手的控件**：开关项改用开关按钮，少量选项（格式、默认动作、帧率、主题）改用分段选择。
- **快捷键录制框**：点击后直接按下组合键，Esc 取消，Backspace 恢复默认；新快捷键立即注册，被占用时就地提示。录制期间会暂停全局热键，所以也能重新录入当前的组合。
- **保存位置与文件名**：保存位置旁加了「打开文件夹」按钮，文件名规则实时预览。
- **上传**：只显示所选服务需要的参数。
- **关于页**：显示版本和上次检查更新的时间，提供检查更新、GitHub 和日志文件夹入口。
- **即时生效**：去掉了「确定 / 取消」，修改立即保存；输入有误时就地标红提示。
- **窗口**：可缩放，会记住大小；侧栏宽度随语言调整，英文不会被截断；浅色和深色主题都已适配。

## 改进

- **首次运行提示**：首次启动时托盘气泡会说明截图快捷键和常用入口，点击提示可打开设置。
- **历史为空**：历史窗口没有记录时显示提示文字，并禁用相关按钮。
- **自定义上传**：请求头改为停止输入约 0.5 秒后再加密保存，不再每按一次键就写一次；关闭窗口时会保存未写入的内容。
- **翻译**：翻译文件已用 lupdate 重新同步，清理了 10 条过时条目，英文翻译完整。

## 已知问题

- 选区不能跨显示器：混合 DPI 下无法保证像素精确，因此按屏选区。
- 以下情况录屏会改用 GDI，CPU 占用较高：旋转屏、跨显示器区域、部分远程桌面。GIF 最多 256 色，暂不支持录音。
- 钉图 / 历史再编辑时，比屏幕大的图片会先缩小到屏幕大小。
- 切换语言时，已经打开的识别结果窗口不会刷新文字，重新打开即可。
- 未登录 GitHub 的更新检查受频率限制（每 IP 每小时 60 次）。
