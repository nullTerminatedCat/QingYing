# 青影 v0.4.1

本版本是 0.4.0 之后的两轮打磨，侧重稳定性与使用体验。提供 Windows x64 安装包（setup.exe）和免安装 ZIP（portable.zip），并附 SHA256SUMS 校验文件。0.4.0 用户可通过托盘「检查更新」直接升级。

## 新增

- **钉图编辑标注**：在钉图右键菜单选「编辑标注」或按 `E`，会在原位置打开截图编辑器继续标注。完成后替换原钉图，取消则恢复原样。
- **历史再编辑**：在历史记录窗口点「编辑标注」，会在屏幕中央打开编辑器。
- **定时截图**：托盘「定时截图」可选每 10 秒、30 秒、1 分钟或 5 分钟，自动把全屏截图保存到保存位置（多显示器各存一张）。
- **默认工具与颜色**：框选完成后自动选中设置好的标注工具和颜色。
- **即时切换语言**：在设置里改语言后立即生效，无需重启；Qt 自带的对话框（按钮、文件选择框）也会同步翻译。
- **诊断日志**：日志和崩溃转储（minidump）保存在 `%LOCALAPPDATA%\QingYing\QingYing\logs`，反馈问题时可附上。

## 改进

**录屏**
- 优先使用 Desktop Duplication（DXGI）抓帧，只回读选区，CPU 占用更低；不可用时自动改用 GDI。
- 鼠标指针按 DXGI 帧信息绘制（形状、热点和位置均为物理像素），支持彩色、掩码和单色指针。
- GIF 改为中位切分自适应调色板，约每 2 秒或画面切换时重建，减少闪烁和色带跳变；可在设置中开启 Floyd–Steinberg 抖动。编码在后台线程进行，连续相同的帧会合并。
- 控制条显示录制文件大小估计。

**界面**
- 托盘菜单图标随浅色 / 深色主题变色。
- 设置中的数字框和下拉框改用统一的箭头样式。
- 检查了英文界面布局。

## 修复

- 文字识别（OCR）进行中退出程序可能崩溃。
- 录屏时退出程序，文件可能没写完。
- 钉图编辑偶尔没有打开（改为等屏幕刷新完成后再进入编辑，不再依赖固定延时）。
- 更新检查：预发布版本（如 `-beta`）不再被当作比正式版更新的版本；SHA256SUMS 支持 `*文件名` 格式。

## 开发

- 新增 QtTest 单元测试：长截图拼接、文件名规则、取色格式、版本比较、SHA256SUMS 解析、JSON 路径、GIF 调色板与抖动、指针合成。CI 每次推送都会运行。
- CI 中的 actions/checkout 与 upload-artifact 升级到 v5。

## 已知问题

- 选区不能跨显示器：混合 DPI 下无法保证像素精确，因此按屏选区。
- 以下情况录屏会改用 GDI，CPU 占用较高：旋转屏、跨显示器区域、部分远程桌面。GIF 最多 256 色，大面积渐变开启抖动后仍会有颗粒感。暂不支持录音。
- 钉图 / 历史再编辑时，比屏幕大的图片会先缩小到屏幕大小。
- 切换语言时，已经打开的识别结果窗口不会刷新文字，重新打开即可。
- 未登录 GitHub 的更新检查受频率限制（每 IP 每小时 60 次）。
- 开发测试中曾出现一次程序被托盘「退出」操作关闭，原因未确认；之后连续 43 次未再出现。日志会记录每次退出的来源。
