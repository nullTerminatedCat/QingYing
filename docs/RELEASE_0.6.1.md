# 青影 v0.6.1

本版为 MP4 录屏增加可选麦克风录音。

## 实际改进

- **录制麦克风（MP4）**：设置 → 录屏可开启；默认关闭。使用 WASAPI 采集默认麦克风，经 Media Foundation 编码为 AAC 并写入同一 MP4。
- **GIF 不录音**：GIF 仍为无声动画；设置项说明中已注明。
- **失败不中断**：无麦克风、无权限或 AAC 不可用时给出中文提示，并继续无声录制，不会崩溃。
- **迷你控制条**：MP4 录制时显示麦克风按钮，可查看状态并在录制中静音 / 恢复。
- 新增与修改的界面文案提供简体中文和英文。

## 验证

- 本机 Release x64 零警告编译；QtTest 全部通过。
- 冒烟脚本覆盖启动、系统 OCR、语言切换与录屏路径；麦克风默认关闭，不依赖本机录音硬件。
- 手动建议：设置中开启麦克风后录制短 MP4，确认有音轨；关闭权限或拔掉麦克风时能看到提示且视频仍能保存。
